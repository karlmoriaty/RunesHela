CI：GitHub Actions `ubuntu-latest`（性能门禁）、`windows-latest`、`macos-14`（AOT 矩阵）。

## 2. 本轮热路径改动（T-027）

| 改动 | 目的 |
|---|---|
| 选项名先比较长度，再做 `OrdinalIgnoreCase` 比较 | 避免每个选项都走完整字符串比较 |
| 短选项改为生成 `switch (name[0])` | 消除 if/else 链 |
| 枚举解析增加长度前置判断 | 减少字符串比较次数 |
| `WantsJson` 只扫描一次，作为参数传入绑定器 | 省去每次绑定的重复扫描 |
| 位置参数复用原始 `string`（`CommandLineToken.Source`） | 字符串位置参数不再复制 |
| 字符串选项继续使用 `SpanText`（整串复用） | 分离值/整段内联零分配 |

## 3. 绑定基准（5 选项 + 1 位置参数）

```powershell
dotnet run --project benchmarks/RunesHela.Benchmarks -c Release -- --filter "*BindingBenchmarks*" --job short
```

| 方法 | Mean | Allocated | 说明 |
|---|---:|---:|---|
| FiveOptions | 201.82 ns | 56 B | 56 B = `Bind5Command` 实例本身 |
| NoOptions | 14.61 ns | 24 B | 24 B = `Cmd0` 实例本身 |

**解读**：

- 框架净分配 = 0 B（5 选项 + 1 位置参数），满足 NFR-01 的分配口径（不含用户命令实例）。
- 绑定耗时 **201.82 ns**，低于 1 µs 预算（约 5× 余量），也低于失败阈值 1.1 µs。
- 位置参数改为复用原字符串后，分配从 88 B 降至 56 B（仅剩命令实例）。

## 7. 性能门禁（T-028 / T-032 / AC-14）

新增 `tests/RunesHela.Performance.Tests`，在 Release 下用
`GC.GetAllocatedBytesForCurrentThread` 与 `Stopwatch` 断言绝对预算：

| 断言 | 阈值 | 结果 |
|---|---:|---|
| 5 选项绑定的净分配 | 0 B（与同形状无选项命令对比） | ✅ 0 B |
| 帮助分配 | ≤ 128 B | ✅ 0 B |
| 错误分配 | ≤ 1024 B | ✅ 304 B |
| 绑定+派发耗时 | ≤ 1100 ns | ✅ ~200 ns |
| 帮助耗时 | ≤ 5500 ns | ✅ ~13 ns |
| 错误耗时 | ≤ 5500 ns | ✅ ~58 ns |
| 错误退出码 | 2 | ✅ |

CI `build-test` 与独立 `perf` job 均执行该套件；`perf` 另运行完整微基准并上传 JSON 产物。

## 8. AOT 与发布矩阵（T-030 / AC-13）

### 8.1 本地验证（Windows）

| 配置 | 命令 | 结果 |
|---|---|---|
| Trim + SingleFile（linux-x64） | `dotnet publish -p:PublishAot=false -p:PublishTrimmed=true -p:PublishSingleFile=true -p:SelfContained=true` | ✅ 0 警告 |
| ReadyToRun（linux-x64） | `dotnet publish -p:PublishAot=false -p:PublishReadyToRun=true -p:SelfContained=false` | ✅ 0 警告 |

生成器项目新增 `TreatAsLocalProperty`，使裁剪/单文件/R2R 全局属性不会误流向 `netstandard2.0` 分析器。

### 8.2 CI 矩阵

| RID | Runner | 配置 | 冒烟 |
|---|---|---|---|
| linux-x64 | ubuntu-latest | AOT | `--help`、`greet Ada -t Hi` |
| win-x64 | windows-latest | AOT | 同上 |
| osx-arm64 | macos-14 | AOT | 同上 |
| linux-x64 | ubuntu-latest | Trim + SingleFile | `--help` |
| linux-x64 | ubuntu-latest | ReadyToRun | `--help` |

> 6 RID 全覆盖（含 musl/arm64 交叉工具链）留待 M8 发布演练（T-055）；本轮先覆盖三条主流桌面/服务器 RID。

### 8.3 AOT 体积

M2 实测增量 125.8 KB（超 100 KB 目标、低于 150 KB 失败阈值）。M3 本轮未做体积专项优化（T-030 只建矩阵）；体积回退记录在 [M2 报告](./M2-基准报告.md)，M8 发布前必须收敛到 ≤ 100 KB。

## 9. DI 适配（T-035）

M2 已实现构造注入；M3 补充验证：

- 无 `IServiceProvider` 且命令需要依赖 → 退出码 1、`RHL_DI_SERVICES_MISSING`、不挂起。
- 提供容器但缺少服务 → `RHL_DI_SERVICE_MISSING` + `nextSteps`。
- 参数化构造 + 选项绑定的组合在集成测试中通过。
