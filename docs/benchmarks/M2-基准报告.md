# M2 基准报告（绑定与 MVP）

> 项目：**RunesHela**
> 阶段：M2（T-015 ~ T-026）
> 日期：2026-11-27
> 结论：**M2 性能未回退。** 帮助仍为 0 B；错误路径因为结构化错误信封产生 304 B 分配，仍低于 512 B 预算；路由的 24 B 为用户命令实例。

## 2. 框架路径（10 命令）

```powershell
dotnet run --project benchmarks/RunesHela.Benchmarks -c Release -- --filter "*FrameworkBenchmarks*" --job short
```

| 方法 | M0 | M2 | Allocated（M2） | 预算 | 结论 |
|---|---:|---:|---:|---:|---|
| Help（`--help`） | 5.98 ns | 11.66 ns | 0 B | ≤ 5 µs / ≤ 64 B | ✅ |
| Error（未知命令） | 7.77 ns | 76.94 ns | 304 B | ≤ 5 µs / ≤ 512 B | ✅ |
| Route（`cmd5`） | 5.67 ns | 14.48 ns | 24 B | ≤ 1 µs / 0 B（不含用户对象） | ✅ |

**解读**：

- 帮助仍写入 `const string`，分配 **0 B**；耗时增加来自根帮助包含退出码与命令列表。
- 错误路径由“两行文本”升级为 `RunesHelaError`（code/hint/nextSteps/docsUrl/exitCode）：字符串拼接 + 数组 + 对象，实测 **304 B / 77 ns**，在 512 B 预算内。`docsUrl` 已改为编译期常量，避免每次拼接（优化前 584 B）。
- 路由的 24 B 是 `Cmd5` 命令实例，按预算口径不计入框架分配（M3 会单独报告“框架净分配”）。
- 解析基准未变化（未改动 `CommandLineReader` 热路径；仅新增 `PrefixLength` 字段读取）。

## 3. 功能验证（非性能）

M2 新增 31 个集成测试（真实编译 + 执行），覆盖：

| AC | 验证点 | 测试 |
|---|---|---|
| AC-01 | 纯 POCO 绑定、默认值、ENV、必填 | `BindsArgumentAndOptions`、`ReadsEnvironmentVariables`、`ReportsMissingRequiredOption` |
| AC-02 | 3 层嵌套命令帮助与路径 | `NestedCommandHelpUsesFullPath` |
| AC-09 | `--help --json` 固定 Schema | `JsonHelpExposesMachineReadableModel`、`RootJsonHelpListsCommands` |
| AC-16 | 生成期诊断 | 生成器测试 50 项（重名/必填+默认/不支持类型等） |
| AC-17 | Secret 脱敏 | `SecretValuesAreRedacted` |
| AC-18 | `NO_COLOR`/TTY/无 ANSI | `AnsiEscapesAreOnlyWrittenWhenEnabled`、`HelpNeverContainsAnsiEscapes` |
| AC-19 | 80 列下的中文帮助 | 快照 `OptionsAndHelp.verified.g.cs`（CJK 描述，无截断/错位） |

测试总数：运行时 22 + 生成器 50 + 集成 31 = **103**，全部通过。
