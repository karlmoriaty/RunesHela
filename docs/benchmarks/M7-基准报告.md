## 2. Manifest

```json
{
  "schemaVersion": "1.0",
  "kind": "mcp",
  "application": "AotCli",
  "tools": [
    {
      "name": "greet",
      "description": "Print an AOT-friendly greeting.",
      "inputSchema": {
        "type": "object",
        "properties": {
          "name": { "type": "string", "x-runeshela-position": 0 },
          "text": { "type": "string", "default": "Hello", "x-runeshela-option": "text" }
        },
        "required": [],
        "additionalProperties": false
      },
      "annotations": {
        "readOnlyHint": false,
        "destructiveHint": false,
        "idempotentHint": true,
        "openWorldHint": true
      },
      "x-runeshela-path": "greet"
    }
  ]
}
```

- 仅包含**可执行**（有 handler）且未隐藏的命令；嵌套路径转为 `parent_child_leaf`。
- 参数属性名默认小写 kebab；与选项重名时自动加 `arg-`/`opt-` 前缀，CLI 映射由扩展字段保证。
- 破坏性命令额外提供 `yes: boolean`，映射为 `--yes`。
- `[Secret]` 不输出默认值；隐藏选项不进入 Schema。

## 3. stdio server

| 方法 | 行为 |
|---|---|
| `initialize` | 回显客户端 `protocolVersion`（缺省 `2024-11-05`），声明 `tools` 能力与 `serverInfo` |
| `notifications/initialized` | 无响应 |
| `ping` | 空结果 |
| `tools/list` | 返回 Manifest 中的工具数组 |
| `tools/call` | 参数映射为 CLI argv，执行命令并捕获 stdout/stderr |

示例：

```text
→ {"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"greet","arguments":{"name":"Ada","count":2}}}
← {"jsonrpc":"2.0","id":3,"result":{"content":[{"type":"text","text":"Hello, Ada!\nHello, Ada!\n"}],"isError":false,"structuredContent":{"exitCode":0}}}
```

- 参数映射：位置参数按 `x-runeshela-position` 排序；选项按 `x-runeshela-option`；布尔 false 在可否定旗标上转为 `--no-x`，否则省略。
- 数组：JSON 数组逐项传递；对象/嵌套数组返回 `-32602`。
- 执行：临时替换 `RunesHelaConsole`、`Console.Out/Error` 捕获输出；交互控制台被标记为输入重定向，破坏性命令必须显式 `yes: true`，不会挂起。
- 结果：`content` 文本项 + `isError` + `structuredContent.exitCode`；CLI 错误（缺失必填、校验、确认）不转成协议错误。
- 协议错误：`-32700` 解析失败、`-32600` 非法请求、`-32601` 未知方法、`-32602` 未知工具/参数。

## 4. 与 CLI 的一致性

集成测试 `McpManifestMatchesDescribeModel`：

1. 工具名集合包含 `greet`/`deploy`/`parent_child_leaf`，不包含无 handler 的 `pending`。
2. `greet.count`、位置参数、数组、布尔类型与默认值来自同一模型。
3. `deploy.environment` 为 `required`。
4. `purge` 的 `destructiveHint=true`、`idempotentHint=false`；普通命令相反。

`McpStdio*` 测试覆盖：初始化、通知无响应、工具列表、调用成功、破坏性拒绝/确认、缺失必填、未知工具/参数/方法、非法 JSON。

## 7. 与设计的差异

1. **内置而非独立包**：设计 §4.1 预留 `RunesHela.Mcp` 可选包；M7 将其实现为生成入口内置命令（同 `describe`/`schema`），保持单包、零依赖与产物同源。若后续需要减小体积，可按应用开关裁剪。
2. **单线程顺序处理**：当前逐行顺序执行，不支持并发调用与 `notifications/cancelled` 中断；MCP 客户端常规串行调用不受影响。
3. **注解保守默认**：`CommandAttribute` 尚无 `IsReadOnly`/`IsIdempotent`，`readOnlyHint` 固定 false、`idempotentHint` 取 `!IsDestructive`；后续可扩展元数据。
